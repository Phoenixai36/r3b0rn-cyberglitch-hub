## Operating protocol
Preserve primary evidence. Build the 10.000×20 dataset without overwriting historical values. Implement transformations as deterministic code. Register parameters and seeds. Run null models. Separate discovery from validation. Preserve negative and failed results.

## Priority order
A. Source integrity and provenance.
B. Complete data reconstruction.
C. Literal Nona reconstruction.
D. Formal P0/P1/P2 implementation.
E. Statistical/null testing.
F. Blind validation of special targets.
G. Astronomical comparison only after the above is frozen.

## Stop conditions
Stop and flag an issue when source evidence is ambiguous, a transformation requires arbitrary tuning, or a result depends on a target selected after inspection.

## Required output
Produce machine-readable data and human-readable reports. Every positive result must include the exact transformation, parameters, controls, search space, effect size and reproducibility information.
