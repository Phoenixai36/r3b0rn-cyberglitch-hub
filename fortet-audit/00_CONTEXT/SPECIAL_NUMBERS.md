# SPECIAL_NUMBERS

## Classification

### From the Fe de Erratas — primary correction targets
1450, 4504, 1630, 3529, 5876, 5943, 7058, 7069, 9433, 9461, 8181, 8474, 8987.

### From the separate “Para mayor exactitud” note
1231, 1777, 2473, 3089, 3181, 9118, 9696.

### Later research/target numbers
6, 13, 185, 494, 618, 1618 and any astronomical target must be treated as hypothesis/validation material unless a primary source independently establishes their relevance.

## Important distinction
A number appearing in the Fe de Erratas is evidence that Fortet's table has a documented correction associated with that number. It is NOT automatically evidence that the number is a hidden key or intentional target.

## 8181
The Fe de Erratas explicitly states that the last decimal digit for 8181 is 7. This makes 8181 an especially useful audit case because it has primary-source relevance, but it still does not establish a code.

## 618 / 1618 / other targets
These must remain separated from the primary errata unless a source connects them. They are useful only as predeclared validation candidates or hypotheses.

## Required experiment discipline
Do not tune transformations to make any of these numbers appear. Freeze the transformation first, then test the targets. Keep discovery and validation datasets separate.
